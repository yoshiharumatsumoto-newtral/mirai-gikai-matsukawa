# 松川村議会AIインタビュー 画面文言案

国会・チームみらい向けに書かれている画面の文言を、松川村向けに置き換える案。
【運営者名】は実施する人・団体の名前に置き換える（例: 「松本〇〇（松川村在住）」「松川村の議会を考える会」）。

---

## 先に決めること

1. **運営者名**：回答者が「誰に答えているか」が分かるよう、全画面で同じ名前を使う。
2. **回答の使い道**：下の案は「匿名で集計・要約し、村議会への提言や一般質問の材料にする」としている。運営者が議員・候補者かどうかで書き方が変わる。
3. **回答の公開**：回答者が許可した場合に、要約と原文を匿名でこのサイトに掲載する（元の仕組みのまま）。
4. **有識者リスト登録**：氏名・連絡先を集める機能。小さな村では個人が特定されやすいので、**非表示を推奨**。
5. **サービス名とロゴ**：公開する場合、FORK_GUIDELINES.md により「みらい議会」の名前・ロゴ・色は変更が必要。案: 「松川村 議会への声」。

---

| いまの文言 | 案 |
|---|---|

| さまざまな意見が公開されることで、より深い法案議論が実現できます。 | さまざまな声が見えるようになることで、村議会についての話し合いが深まります。 |
| 非公開で提出した場合でも、ご意見は党内での政策検討に活用させていただきます。 | 非公開で提出した場合でも、ご意見は匿名で集計・要約し、村議会への提言に活用させていただきます。 |
